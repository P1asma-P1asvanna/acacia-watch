Put minigame videos / audio here (MP4, WebM, MP3, OGG, M4A), then git add, commit and push.
They appear in the GM's Minigame -> media library. One file must stay under 100 MB (GitHub limit); keep the whole folder small (a few hundred MB at most).
Tip: 720p, H.264 + AAC, "fast start" (ffmpeg -movflags +faststart) plays best on phones.
